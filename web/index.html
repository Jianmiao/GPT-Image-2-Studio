让创作更简单

  1. 连接供应商

    在左下角「设置」中填写供应商地址和 API Key，获取模型后保存。

  2. 描述你的画面

    输入提示词，选择模型、比例和风格。也可以用模板开始，再改成自己的想法。

  3. 用参考图继续创作

    点击输入框旁的加号上传图片，或直接粘贴。用「图1」「图2」说明你想保留或修改的内容。

  4. 保存与回看

    生成的图片会自动保存在本机，可以从左侧历史记录回看、下载和复用提示词。

关于生成

每次点击只提交一次生成请求，失败不会自动切换接口重发。出现网络错误时，请先核对供应商的任务记录，再决定是否重新生成。

自定义尺寸支持 1024x1536 或 1024*1536，输入 * 会自动纠正为 x。

图片保存在 .gptimage2/gallery/，提示词和生成记录保存在 .gptimage2/history.json。
