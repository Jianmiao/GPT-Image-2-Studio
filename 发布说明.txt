GPT Image 2 Studio 1.1.0 —— 使用说明
========================================

这是什么
--------
一个跑在自己电脑上的生图工具：填入第三方中转站（OpenAI 兼容网关）的地址和 API Key，
就能调用 gpt-image-2 等模型文生图 / 图生图。不需要安装依赖，不需要 npm。


一、准备工作
------------
1. 安装 Node.js 18 或更高版本：https://nodejs.org/
   （安装时一路下一步即可，装完不用重启电脑）
2. 解压本压缩包到任意目录（路径里有中文也没关系）


二、启动
--------
双击「启动工具.bat」

  - 会弹出一个黑色命令行窗口，显示本地地址 http://127.0.0.1:8787
  - 浏览器会自动打开这个地址
  - 【重要】这个黑窗口不要关，关掉就等于停止服务
  - 想停止服务：在窗口里按 Ctrl + C，或直接关掉窗口

端口被占用时，在命令行里执行：node server/cli.js --port 8899


三、三个步骤开始出图
--------------------
1. 打开左下角「设置」，填写供应商地址，例如 https://api.example.com
   带不带 /v1 都行，粘贴整条接口地址也会被自动裁剪。
2. API Key：填中转站给你的令牌，可点「获取模型」，最后点「保存设置」。
   工具会自动拉取该站的模型列表，筛出图像模型并优先排序。
3. 底部选择模型、比例、风格，写提示词后点发送箭头（Ctrl + Enter 也可以）。

想改图就点加号或拖入参考图（最多 10 张），再描述要怎么改。
左侧可以搜索、回看历史记录；点「新建图片」开启新的创作。
尺寸支持 1024*1536，应用后会自动转为 1024x1536。
每次生成只提交一次，发生错误不会自动换接口或格式重发。


四、常见问题
------------
* 报 fetch failed，但浏览器能打开那个网站
  → 是代理问题：浏览器走系统代理，Node 默认直连。
    在「网络代理」里点「探测」查看当前出口；探测不到就手填，例如 http://127.0.0.1:7890

* 报"域名解析失败"
  → 该域名在 DNS 里不存在，先确认中转站给的地址是否还有效。

* 报 401 / 403
  → 密钥无效，或该密钥所在分组没有图像模型权限。

* 报 404 / model not found
  → 模型名要用列表里的准确 ID（有的站是 gpt-image-2-vip、gpt-image-2-all 之类）。

* 报 400 参数错误
  → 先用 1024x1024 + 质量 auto 跑通，再逐项加参数。自定义尺寸宽高都要能被 16 整除。

* 某个模型一直转圈最后失败
  → 多半是该模型在这家中转站上排队或本身就慢，换成 gpt-image-2 试。


五、数据存在哪里
----------------
第一次运行后，工具目录下会自动生成 .gptimage2 文件夹：

  .gptimage2/config.json    你的地址、密钥与参数（只存在本机）
  .gptimage2/history.json   生成历史
  .gptimage2/gallery/       生成的图片

想彻底清空，删掉 .gptimage2 文件夹即可。
密钥保存在本机，只发送给你设置的供应商进行鉴权，不会上传到 GitHub。


六、想先空跑熟悉界面（可选，不需要真实密钥）
--------------------------------------------
工具自带一个模拟中转站：

  1) 在工具目录打开命令行，执行： node test/mock-relay.js --port 8899
  2) 界面上填地址 http://127.0.0.1:8899，密钥填 sk-mock-token，
     并勾选「允许内网 / localhost 地址」
  3) 点「获取模型」，即可用假数据跑通全流程

跑自动化测试：node test/run-all.js   （仅模拟数据，不使用真实密钥生图）

安卓版本：安装 APK 后在手机设置里填写供应商地址和密钥即可使用，无需电脑运行。
手机与电脑的数据分别保存，不会自动同步。


七、安全说明
------------
* 服务只监听 127.0.0.1，仅在你自己电脑上可访问；
* 默认禁止把请求发往内网 / localhost 地址（防止密钥被误发），自建中转需手动勾选允许；
* 本压缩包内不含任何 API Key，密钥需要你自己填写。
